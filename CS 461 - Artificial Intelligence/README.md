# CS 461 - Artificial Intelligence

This folder contains the code and final report for the course project of **CS 461 - Artificial Intelligence**: a **Snake Game** agent trained using reinforcement learning.

## Contents

- `agent.py` — The reinforcement learning agent that learns to play the Snake game.
- `game.py` — The Snake game environment/logic.
- `model.py` — The neural network model used by the agent.
- `helper.py` — Helper functions (e.g., for plotting training progress).
- `arial.ttf` — Font file used for rendering text in the game.
- `CS461_Final_Report_Team7.pdf` — The final report submitted for the project.
